Cómo trabajé el proyecto

Estos son los pasos que seguí, en el orden en que los hice. Cada uno dejó una evidencia en la terminal o en GitHub.

  1. Configuré Git. Le indiqué mi nombre y correo para que cada commit quede a mi nombre. git config --global user.name "Enid Robles"
  2. Creé el repositorio local. En la carpeta mi_proyecto_git creé este archivo index.html e inicié el repositorio. git init
  3. Hice el primer commit. Pasé el archivo al área de preparación y guardé la primera versión. git add index.html git commit -m "Crea index.html con la estructura basica"
  4. Modifiqué el archivo. Agregué un título y un párrafo de presentación y guardé el cambio en un nuevo commit. git commit -m "Agrega titulo y parrafo de presentacion"
  5. Agregué el contenido y un README. Escribí mis datos y el resumen del trabajo, y un README que describe el proyecto. Cada cosa quedó en su propio commit. git commit -m "Agrega datos de Enid Robles y pasos del trabajo" git commit -m "Agrega README con la descripcion del proyecto"
  6. Trabajé los estilos en una rama aparte. Así probé el diseño sin tocar la versión principal, y después fusioné la rama con main. git checkout -b estilos git commit -m "Agrega estilos CSS con los colores de la ESPE" git checkout main git merge estilos
  7. Publiqué en GitHub. Creé un repositorio público, lo vinculé con el local y subí la rama principal y la rama de estilos. git remote add origin https://github.com/enidrobles/mi_proyecto_git.git git push -u origin main git push origin estilos

Lo que aprendí

Git no guarda el archivo cada vez que lo edito. Primero trabajo en mi carpeta, luego elijo qué cambios quiero guardar con git add y después los confirmo con git commit. Así el historial cuenta qué cambió y cuándo, y puedo volver a una versión anterior si me equivoco.

Las ramas me permiten probar un cambio sin arriesgar lo que ya funciona, y GitHub guarda una copia del historial en internet. Con git push envío mis commits ahí, y como el repositorio es público, cualquier persona con el enlace puede revisarlo.
